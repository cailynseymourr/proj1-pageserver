## Description

This project implements a simple HTTP server in Python.
It serves static files from the 'pages/' directory and responds to requests using a custom socket-based server. The project includes a Makefile for running and stopping the server, as well as automated tests under the 'tests/' directory.

## How to Run
make run

Then visit:
http://localhost:5000

To stop the server:
make stop

## Testing
Automated tests are provided in the 'tests/' folder.

Because I am on windows I ran them with bash tests.sh http://localhost:5000 in a Linux environment (WSL2)
